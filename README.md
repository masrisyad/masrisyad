## 💼 Freelance Services

I build small, reliable Python tools that remove repetitive data work:

| Service | What you get |
|---|---|
| **Web scraping** | Catalogue, listing or lead data exported to clean CSV / Excel, with pagination, retries and rate limiting |
| **Excel report automation** | Messy CSV exports merged and cleaned into a formatted report with KPIs, pivots and native charts |
| **PDF data extraction** | Invoices, statements and forms turned into structured spreadsheets with built-in validation |
| **Test automation** | End-to-end and API test suites with Playwright, pytest and GitHub Actions |

📂 Sample projects with runnable code and sample output: **[python-automation-portfolio](https://github.com/masrisyad/python-automation-portfolio)**

Async-first: clear written updates and screen recordings, no meetings required. Every delivery includes source code and a README.
